# Guía docente

## Preparación semanal

1. Ejecute el notebook en un ambiente limpio.
2. Verifique enlaces y disponibilidad de servicios externos.
3. Publique la actividad en GitHub Classroom o el LMS institucional.
4. Defina qué partes se harán en Colab, terminal local y Apolo.
5. Prepare un fallo deliberado que los estudiantes deban diagnosticar.

## Ritmo sugerido de una sesión de 3 horas

- 20 min: problema biológico y criterios de éxito.
- 35 min: conceptos y demostración.
- 65 min: laboratorio guiado.
- 40 min: reto en parejas.
- 20 min: puesta en común, límites y cierre.

## Gobernanza

- Proteja la rama principal y exija pull request y validación automática.
- Use `CODEOWNERS` para materiales sensibles o evaluaciones.
- No permita carpetas personales en la raíz.
- Archive cada edición con un tag (`2026-1`, `2026-2`).
- Revise ambientes y enlaces antes de cada semestre.
