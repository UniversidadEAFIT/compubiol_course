# Datos didácticos

Todos los archivos son pequeños y fueron creados para enseñanza. Las secuencias marcadas como sintéticas no representan genes ni genomas reales. No deben utilizarse para investigación o diagnóstico.

Cada subcarpeta documenta propósito, formato y limitaciones. Los datos grandes o con licencias restrictivas no se versionan: deben descargarse mediante un script, identificador persistente y checksum.
