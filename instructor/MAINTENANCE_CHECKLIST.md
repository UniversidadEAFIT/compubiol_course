# Lista de mantenimiento semestral

## Antes de abrir el curso

- [ ] Crear tag de la edición anterior.
- [ ] Reconstruir `environment.yml` en Linux limpio.
- [ ] Ejecutar `python scripts/validate_repo.py`.
- [ ] Ejecutar `bash scripts/run_smoke_tests.sh`.
- [ ] Probar enlaces Colab.
- [ ] Confirmar módulos, particiones, cuentas y límites vigentes en Apolo.
- [ ] Revisar que referencias y documentación oficial sigan activas.
- [ ] Crear asignaciones en GitHub Classroom.
- [ ] Confirmar licencias de nuevos datos o figuras.

## Después del curso

- [ ] Integrar solo correcciones generalizables.
- [ ] No fusionar entregas completas a la rama principal.
- [ ] Cerrar issues del semestre.
- [ ] Crear tag `YYYY-periodo` y notas de versión.
